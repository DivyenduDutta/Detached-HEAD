# Detached-HEAD
A puzzle game where you predict what git will do to a diagram, then watch what it actually does.

Players come out the other end with a clearer understanding of Git's mental model.

### Setup

1. Install [uv](https://docs.astral.sh/uv/)
2. Create the venv and install dependencies from `uv.lock` use `uv sync`

### Run

1. Activate virtual environment using `.venv\Scripts\activate`
2. Run using `uv run detached-head`
